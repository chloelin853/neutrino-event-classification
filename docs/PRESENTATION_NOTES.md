# Presentation provenance

The guided notebook and README graphics were added during portfolio preparation with AI assistance. The original coursework notebooks remain under `notebooks/logbooks/`, with their existing outputs. New presentation work should not be described as an independently completed part of the original assignment.

Guided notebook code was executed in order in a fresh Python namespace during preparation; outputs are embedded. This was not a full Jupyter-kernel or original-logbook rerun. Both guided notebooks require only NumPy and Matplotlib for their analysis cells. Dependency versions used for verification: Python 3.12, NumPy 2.5.3, Matplotlib 3.11.2. Dependency lists remain unpinned for now.
